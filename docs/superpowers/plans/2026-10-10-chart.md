# Chart Command Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `/chart` with period buttons, multi-panel CBR rate image, and a `/rate` hint pointing to it.

**Architecture:** Extend the CBR client with `XML_dynamic.asp` and internal currency IDs. Pure helpers compute the Moscow date window, extrema, caption, and PNG (matplotlib Agg). A new handler sends/edits a photo with an inline period keyboard. No history in PostgreSQL.

**Tech Stack:** Python 3.12, aiogram 3.15, aiohttp, matplotlib (Agg), existing Decimal/XML parsing patterns.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-10-09-chart-design.md`
- Chart Y values: rubles per 1 unit (`Value / Nominal` or `VunitRate` when present)
- Periods: week=7, month=30, half-year=182 calendar days inclusive from today MSK
- Caption max 1024 chars; emoji flags only in caption, never on the PNG
- Do not commit unless the user explicitly asks
- Prefer unit tests without network; clear in-memory caches in tests via existing `clear_cache` + new dynamic cache clearer

### Task 2: Dynamic series client

**Files:**
- Modify: `clients/cbr.py`
- Modify: `tests/unit/test_cbr.py`

**Interfaces:**
- Consumes: `cbr_id`, date strings `dd/mm/yyyy`
- Produces:
  - `CbrSeriesPoint(date: date, nominal: int, value: Decimal, unit_rate: Decimal)`
  - `parse_cbr_dynamic_xml(xml_text: str) -> list[CbrSeriesPoint]` (sorted by date ascending)
  - `async def get_dynamic_rates(cbr_id: str, date_from: date, date_to: date, *, force_refresh: bool = False) -> list[CbrSeriesPoint]`
  - `clear_dynamic_cache() -> None`
- Cache: in-memory dict keyed by `(cbr_id, date_from.isoformat(), date_to.isoformat())`, TTL `_CACHE_TTL` (3600)
- URL: `https://www.cbr.ru/scripts/XML_dynamic.asp?date_req1={dd/mm/yyyy}&date_req2={dd/mm/yyyy}&VAL_NM_RQ={cbr_id}`
- Decode body like daily (windows-1251 fallback)
- `unit_rate`: prefer `VunitRate` if present and valid; else `value / nominal`

  - `def analyze_series(points: list[CbrSeriesPoint]) -> SeriesExtremes | None`  
    Empty → `None`.  
    Peak = max `unit_rate`, ties → latest date.  
    Trough = min `unit_rate`, ties → latest date.  
    `flat = (peak.unit_rate == trough.unit_rate)`.  
    `last = points[-1]`.
