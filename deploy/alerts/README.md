# Vector alerting

[Vector](https://vector.dev) собирает логи и метрики бота и шлёт алерты в Telegram.

## Sources

| ID            | Тип                 | Описание                                              |
|---------------|---------------------|-------------------------------------------------------|
| `bot_logs`    | `docker_logs`       | Логи контейнера `currency-compass-bot`                |
| `bot_metrics` | `prometheus_scrape` | `http://currency-compass-bot:9100/metrics` раз в 60 с |

## Transforms

| ID                       | Описание                                                         |
|--------------------------|------------------------------------------------------------------|
| `filter_log_errors`      | Логи с `ERROR`, `Exception` или `Traceback`                      |
| `throttle_log_errors`    | Не больше одного лог-алерта за 5 минут                           |
| `format_log_alert`       | JSON для Telegram                                                |
| `filter_error_metrics`   | Счётчики из таблицы ниже                                         |
| `detect_increases`       | Lua: рост между скрейпами                                        |
| `throttle_metric_alerts` | Не больше одного алерта на счётчик за 5 минут                    |
| `format_metric_alert`    | «+N за последние 60 сек»                                         |

## Отслеживаемые метрики

| Метрика                                | Условие                                      |
|----------------------------------------|----------------------------------------------|
| `cbr_requests_total`                   | Рост при `result=http` или `result=error`    |
| `db_errors_total`                      | Любой рост                                   |
| `bot_commands_total`                   | Рост при `error`, `cbr_error` или `no_data`  |
| `chart_errors_total`                   | Любой рост                                   |
| `chart_edit_failures_total`            | Любой рост                                   |
| `chart_series_missing_total`           | Любой рост                                   |

Успешные запросы ЦБ и обычные исходы команд (`ok`, `empty`) алертов не дают. Отдельной проверки «ЦБ давно не отвечал» нет: фоновой джобы нет, запрос уходит только когда пользователь открывает курс или график.

## Sink

| ID         | Тип    | Описание                          |
|------------|--------|-----------------------------------|
| `telegram` | `http` | POST `sendMessage` Bot API        |

## Переменные окружения

| Переменная        | Описание                         |
|-------------------|----------------------------------|
| `ALERT_BOT_TOKEN` | Токен бота, который шлёт алерты  |
| `ALERT_CHAT_ID`   | Чат, куда их слать               |

Сервис `alerts` в compose читает `deploy/.env`. Без этих двух переменных контейнер не стартует.

## Как получить `ALERT_CHAT_ID`

Нужен чат, в который этот бот уже может писать. Напишите ему `/start` в личке или добавьте его в группу и отправьте туда любое сообщение. Затем:

```bash
curl "https://api.telegram.org/bot<ALERT_BOT_TOKEN>/getUpdates"
```

В ответе возьмите `message.chat.id`. У личного чата это положительное число, у группы отрицательное. Это значение и есть `ALERT_CHAT_ID`.

Если `result` пустой, бот ещё не видел сообщения. В группе с включённой приватностью он видит только команды, обращения к себе и сообщения после назначения администратором. Напишите `/start@имя_бота` и вызовите `getUpdates` снова.
